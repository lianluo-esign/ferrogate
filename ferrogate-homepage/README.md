# FerroGate Homepage

Static commercial homepage for the GitHub repository website link.

The GitHub Pages workflow publishes this directory as:

```text
https://lianluo-esign.github.io/ferrogate/
```

The FerroGate runtime also embeds `index.html` for the local `/` and
`/index.html` routes, so the product landing page stays aligned between the
repository website and a running gateway.
