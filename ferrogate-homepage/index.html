Whitepaper v0.1 / Self-hosted AI gateway

Route every model through one control plane.

FerroGate defines a minimal gateway layer for AI traffic: one OpenAI-compatible surface, deterministic provider routing, virtual API keys, policy checks, token-budget settlement, observability, and automatic HTTPS. No lock-in, no hosted control plane required.
