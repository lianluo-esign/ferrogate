# Glossary

- **AI gateway**: A service that receives AI API traffic and forwards it to upstream model providers.
- **Provider**: An upstream LLM API vendor or OpenAI-compatible endpoint.
- **Routing**: The process of selecting an upstream provider or model endpoint.
- **Policy hook**: A configurable extension point for auth, quota, auditing, or governance.
- **Quartz**: A static site generator designed for Obsidian-style Markdown vaults.
- **Obsidian vault**: A folder of Markdown notes managed by Obsidian.
